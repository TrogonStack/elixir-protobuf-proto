# Elixir Protobuf Proto

This repository contains the Protobuf file(s) copied from [elixir-protobuf/protobuf](https://github.com/elixir-protobuf/protobuf) for the purpose of publishing to the [Buf Schema Registry (BSR)](https://buf.build).

## Installation

Add to your `buf.yaml`:

```yaml
deps:
  - buf.build/elixir-protobuf/protobuf
```
